Owner Setup

Private owner page (open this site with #setup at the end of the link). Visitors do not see it. Follow these steps once so every order goes into one Google Sheet and to your WhatsApp.

Part 1 · Google Sheet

1. Create a new Google Sheet and name it “Website Orders”.
2. Menu: Extensions › Apps Script.
3. Delete everything, press Copy Apps Script Code below, paste it, and Save.
4. Deploy › New deployment › Web app. Execute as: Me. Who has access: Anyone. Deploy and allow permissions.
5. Copy the Web app URL (ends with /exec).
6. Open this website’s file in a text editor, find var ORDER_API=''; near the top of the script, paste the URL between the quotes, save and upload again.

Part 2 · Automatic WhatsApp message (optional)

1. On callmebot.com follow the WhatsApp steps to activate your number. You will get an API key on WhatsApp.
2. In Apps Script set CALLMEBOT_KEY = 'your key' and save.
3. Deploy › Manage deployments › Edit › New version › Deploy.
CallMeBot is a free third-party service, not official WhatsApp. If ORDER_API is empty, the site still works with the WhatsApp, Email and Copy buttons.
